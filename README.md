# Ink Arena 3D

スプラトゥーン風の「地面を塗って勝つ」3Dブラウザゲームです。  
PCだけでなく iPad のタッチ操作にも対応しています。

## 遊び方

1. ローカルサーバーを起動します。
2. ブラウザで開いて「インクバトル開始」を押します。
3. 床を自チーム色に塗って、90秒後に塗り面積が大きいチームが勝利です。

## 操作

### PC

- `W / A / S / D`: 移動
- `Shift`: ダッシュ
- `Space`: ジャンプ
- `左クリック長押し`: 連射
- `マウス`: 視点移動（ポインタロック）

### iPad / タッチ端末

- 左スティック: 移動
- 右スティック: 視点操作
- `FIRE`: 連射
- `JUMP`: ジャンプ
- `DASH`: ダッシュ

## ステージと敵

- 中央高台＋サイド通路＋遮蔽物で構成したバトルステージ
- 敵キャラ（オレンジチーム）を 8 体配置

## 起動例

```bash
python3 -m http.server 4173
```

その後 `http://localhost:4173` へアクセス。
